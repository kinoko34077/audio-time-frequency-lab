# #20: 周波数別周期窓 → 全観測から共通潜在音響モデルを推定する研究設計

状態: 数学・アルゴリズム設計。試験実装は定常純音1本に限定。現行Pages/RustモデルとM3短長混合は置換しない。

## 1. 研究で解く問題と解かない問題
- 同じPCMについて周波数/時刻/窓長の異なる観測を用い、共通の変数 θ を更新する。各窓で別の音声を合成して混ぜる処理は禁止。
- 観測の数が増えても独立した物理情報が増えるわけではない。窓間の観測ノイズ・サンプルは相関する。二重計数を避け、正規化重み・信頼度を設ける。
- 波形を厳密に復元できても、その物理的発音源、AMと2音、フォルマント等が一意に判定できるとは限らない。採用評価は波形誤差だけでなく識別の安定性・聴感・処理量で行う。

## 2. 数学と時間格子
- 各正の連続周波数 f に窓長 K/f 秒を対応させる。参照整数 n=floor(f+0.5) は候補発見の索引であり、最終 f を整数に丸めない。
- 同じ起点・同じK・整数参照 a,b の正の共通窓終端は K/gcd(a,b)。この値は『特定の2系列』のみの関係。440/441Hz, K=8 は8秒だから、全周波数の厳密同期を必要条件にしない。
- K固定と周波数分解能はトレードオフ（概ね1/T=f/K）。周波数により可変Kと追加長窓を配置する際も、最終推定値は1セットとする。
- 連続時刻の窓中心・境界と離散標本添字を別物として持ち、解析核の重みを標本時刻で評価。補間法・境界延長・窓端規則をテストする。位相原点を絶対時刻へ統一する。
- 整数Hz境界は周波数の物理的『波長』ではない。本プロジェクトの名称『周波数ごとの個別波長』は、音響伝搬距離でなく解析する整数周期に対応した時間窓を指す。

## 3. 次段階の共通潜在モデル（未実装）
- サンプル時刻 t, チャンネル c に対し x_c(t) ≈ Σ_k a_{c,k}(t) cos(phi_k(t)+delta_{c,k}(t)) + r_c(t) と表す。
- theta={連続f_k(t)=phi'_k(t)/(2pi), 包絡a, 初期位相/チャンネル相対位相delta, 音の開始/終了境界, 倍音/AM/FM群の候補, 過渡音と帯域別残差r}。
- 目的関数: L(theta)=lambda_t Σ_c||x_c-G_c(theta)||² + Σ_{w,c}lambda_w||S_w(x_c)-S_w(G_c(theta))||² + mu R(theta)+nu C(theta)。S_wは定義済み観測作用素。各同一サンプルの重複は窓密度で正規化し、可能ならノイズ共分散の影響を評価。
- Rは周波数/位相軌道の不連続性、包絡不自然さ、ステレオ位相ジャンプ、群内部の相対位相矛盾へ独立に作用。Cは過剰な音数・余分な変調/群仮定への複雑さコスト。具体的な重みは検証によって決め、現段階で優位性を主張しない。
- 収束後も信頼区間/複数仮説のスコア差を出す。ステレオ相対位相と絶対位相の自由度（位相ゲージ）を固定し、同値な未知数の重複を避ける。

## 4. 推定アルゴリズムの開発順
1. P1（着手済）: 局所窓で候補周波数を初期発見→7つの K/f 窓から同じ定常 f,a,b を最小二乗推定→元波形との差測定。異なる窓ごとの出力を混ぜない。
2. P2a: 複数成分の発見。既存STFT/CQT/NSGTピークを初期値候補に限定利用し、その解析出力を完成音声とみなさない。重なり成分を同時に含む残差を見ながら、共有thetaを座標降下/限定付き非線形最小二乗で更新。
3. P2b: 位相の時間積分と群整合。各音の周波数軌道・連続初期位相を明示し、窓端/隣接チャンク/倍音群で閉路誤差を測定。群は周波数比だけで物理出自確定しない。
4. P2c: AM対独立2音の競合モデル H_AM, H_SUM を同じPCMへ当てはめ、保留を含むモデル選択結果を出す。波形が同じなら出自の一意識別は不可。群ラベルを断定しない。
5. P3: 発音/消音時刻を未知パラメータとして推定。過渡区間は継続正弦成分から分離。残差を『音程変更の対象/速度だけ/原形保持』へ帯域/統計・オンセット基準で振分け、位相損傷を実測する。
6. P4: f_out(t)=p*f_in(s*t)、phi_out(t)=phi_out(0)+2pi∫f_out(u)du、onset_out=onset_in/s を使う。a_out(t)や残差の規則は実験選択し、どの成分にも一律なpitch移動を掛けない。
7. P5: 正解モデルから合成した出力を改めて全窓で測り直し、分析側S_w(x)との残差と合成波形との誤差を繰り返し評価。改善が不安定ならK/群制約を緩める・別候補法へ経路変更・保留。

## 5. 現行・既存研究との同条件比較
| 方式 | 周波数依存の観測窓 | 共通潜在成分の同時推定 | 留意点 |
| --- | --- | --- | --- |
| 固定STFT / PV | 通常固定 | 通常しない | 過渡/持続の固定時間-周波数折衷、既存プロダクトの基準 |
| CQT | 原理上あり | 標準の係数算出のみではしない | 低域に長窓、高域に短窓。整数周期K/f自体は独創性の証明でない |
| 非定常Gabor/NSGT | あり | 変換の可逆性と音源構造同定は別 | 適切なフレーム条件なら完全再構成可能だが、それは物理的音源の一意識別でない |
| 現行dual | 短長2種 | しない | 個別合成した音声の相関合わせとクロスフェード |
| 今回P1 | K/f の7窓 | 1定常正弦の f,a,b のみ | 条件付き1成分モデル。一般音源品質は未証明 |
| 目標P2以降 | 変化する f,K,オンセットを加味 | 複数軌道・群・残差を一括最適化 | 識別性・頑健性・音質/性能を検証するまで採否保留 |

比較の根拠: Balazs et al., Theory, implementation and applications of nonstationary Gabor frames (2011), https://doi.org/10.1016/j.cam.2011.09.011 ; Holighaus et al., A framework for invertible, real-time constant-Q transforms (2012), https://arxiv.org/abs/1210.0084 . 可逆表現と潜在発音構造の識別を混同しない。

## 6. テストと停止条件（閾値は個別に事前登録）
- 合成の正解付き: 440.4Hz、440対441、110/220/330/550Hz、線形chirp、ビブラート、AMキャリア440Hzと2Hz変調/等価3音、独立2音、打音、帯域ノイズ、ステレオ時間差と逆相。SNR=0/10/20/40dBや欠損サンプルで精度劣化を測る。
- 計測: 周波数軌道誤差、位相閉路誤差、単純正弦波再合成相対誤差、オンセット時刻偏り、ステレオ位相/遅延/振幅、残差の再生成、出力時間T/s、音程倍率p、メモリ峰値、1秒音声あたりの実行時間、音声比較時の聴感差。
- 学習/推定時の窓と評価用の窓は同じ入力から来る。近似合成の検証は未使用区間と異なる分析器、実録音でクロスチェック。単純な多数窓増加だけを情報増と数えない。
- P1受入はPERIOD_JOINT_MODEL.mdの定常純音条件のみ。P2–P5の信頼度・SNR・負荷・位相/オンセット閾値は事前登録が必要。閾値未設定の項目は未受入として扱う。
- 複数成分で従来法を上回る改善が再現しない、AM/独立音解釈が不安定、誤差の減少以上に音質が悪化、モバイル処理に収まらない場合は、可変K・モデル簡素化・保留・中止を評価。合格前の本番切替・品質保証を禁止。
